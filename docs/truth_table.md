# Truth Table & Pattern Specification

## 1. Overview
The **5x5 Electronic Parol Sequencer** decodes a 4-bit synchronous binary count $(A, B, C, D)$ generated by an Arduino Uno into 13 symmetric channel outputs ($X_1$ to $X_{13}$) controlling 25 discrete LEDs.

* **Inputs:**
  * $A$ = Most Significant Bit (MSB, Arduino Pin D7)
  * $B$ = Bit 2 (Arduino Pin D6)
  * $C$ = Bit 1 (Arduino Pin D5)
  * $D$ = Least Significant Bit (LSB, Arduino Pin D4)
* **Outputs:** $X_1$ to $X_{13}$ (Active HIGH, 5V)

## 3. Physical Matrix Spatial Mapping

```
      Col 1    Col 2    Col 3    Col 4    Col 5
Row 1 [ X1  ]  [ X2  ]  [ X3  ]  [ X4  ]  [ X5  ]
Row 2 [ X8  ]  [ X9  ]  [ X10 ]  [ X11 ]  [ X6  ]
Row 3 [ X7  ]  [ X12 ]  [ X13 ]  [ X12 ]  [ X7  ]
Row 4 [ X6  ]  [ X11 ]  [ X10 ]  [ X9  ]  [ X8  ]
Row 5 [ X5  ]  [ X4  ]  [ X3  ]  [ X2  ]  [ X1  ]
```

### Channel Redundancy & LED Count
* **$X_1$:** 2 LEDs at $(1,1)$ and $(5,5)$
* **$X_2$:** 2 LEDs at $(1,2)$ and $(5,4)$
* **$X_3$:** 2 LEDs at $(1,3)$ and $(5,3)$
* **$X_4$:** 2 LEDs at $(1,4)$ and $(5,2)$
* **$X_5$:** 2 LEDs at $(1,5)$ and $(5,1)$
* **$X_6$:** 2 LEDs at $(2,5)$ and $(4,1)$
* **$X_7$:** 2 LEDs at $(3,1)$ and $(3,5)$
* **$X_8$:** 2 LEDs at $(2,1)$ and $(4,5)$
* **$X_9$:** 2 LEDs at $(2,2)$ and $(4,4)$
* **$X_{10}$:** 2 LEDs at $(2,3)$ and $(4,3)$
* **$X_{11}$:** 2 LEDs at $(2,4)$ and $(4,2)$
* **$X_{12}$:** 2 LEDs at $(3,2)$ and $(3,4)$
* **$X_{13}$:** 1 LED at $(3,3)$ [Center Star]

**Total LEDs:** $12 \times 2 + 1 = 25\text{ LEDs}$.
